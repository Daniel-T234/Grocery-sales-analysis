# 🛒 Grocery Sales Analysis

## Project Overview
This portfolio project analyses grocery sales transactions to understand
product performance, outlet performance, sales activity, and ratings.

## Business Questions
- What is total revenue?
- Which product categories generate the most sales?
- Which outlet types perform best?
- How many units are sold?
- How does performance vary by location tier and outlet size?
- How does sales activity vary by establishment year?
- How do ratings differ across outlet types?

## Tools
**Excel • SQL/MySQL • Power BI • Python**

## Dashboard
The planned Power BI dashboard contains:
- Total Sales
- Average Sales
- Total Items
- Average Rating
- Item Type analysis
- Outlet Type analysis
- Outlet Size analysis
- Location Tier analysis
- Establishment-year trend
- Fat-content analysis

understand sales patterns, and support decisions about inventory and outlet
performance.
